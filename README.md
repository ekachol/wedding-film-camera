# กล้องฟิล์มงานแต่ง Sayn & Earth (26.12.2026)

เว็บสำหรับแขกในงาน สแกน QR แล้วถ่ายรูปได้เหมือนกล้องฟิล์มใช้แล้วทิ้ง คนละ 25 รูป รูปของทุกคนรวมอยู่ในอัลบั้มเดียว และบ่าวสาวดาวน์โหลดเก็บได้ทั้งหมด

## มีอะไรบ้าง

- `index.html` หน้าของแขก: หน้าแรก กล้อง และอัลบั้มรวม
- `admin.html` หน้าของบ่าวสาว: ดูจำนวนรูป ดาวน์โหลดทั้งหมดเป็น zip ซ่อนรูป และสร้าง QR code
- `js/config.js` ตั้งค่าทั้งหมด (ชื่อ วันที่ สี จำนวนรูปต่อคน เวลาเปิดอัลบั้ม)
- `supabase/setup.sql` สคริปต์ตั้งค่าที่เก็บรูป

ถ้ายังไม่ใส่ค่า Supabase ใน `config.js` เว็บจะทำงานแบบเก็บรูปไว้ในเครื่องที่ถ่ายเท่านั้น (ไว้ทดสอบ)

ลิงก์หลัก: https://wedding-film-camera-three.vercel.app  ·  หน้าบ่าวสาว: https://wedding-film-camera-three.vercel.app/admin.html

## ขั้นตอนเปิดใช้จริง (ประมาณ 15 นาที ฟรีทั้งหมด)

### 1. สร้างที่เก็บรูปบน Supabase

1. เข้า https://supabase.com กด Start your project แล้วสมัครด้วยบัญชี GitHub
2. กด New project ตั้งชื่ออะไรก็ได้ เลือก Region เป็น Southeast Asia (Singapore) แล้วรอประมาณ 2 นาที
3. เมนูซ้าย เลือก SQL Editor วางเนื้อหาทั้งหมดของไฟล์ `supabase/setup.sql`
4. เลื่อนลงล่างสุด แก้คำว่า `เปลี่ยนรหัสตรงนี้` เป็นรหัสผ่านของบ่าวสาว แล้วกด Run
5. ไปที่ Project Settings > API คัดลอก 2 ค่า คือ Project URL และ anon public key
6. นำ 2 ค่านั้นไปใส่ใน `js/config.js` ที่ช่อง `supabaseUrl` และ `supabaseAnonKey`

ค่า anon key เป็นค่าที่เปิดเผยได้ ออกแบบมาให้อยู่ในหน้าเว็บ ส่วนรหัสผ่านของบ่าวสาวเก็บอยู่ใน Supabase เท่านั้น

### 2. เอาเว็บขึ้นออนไลน์ด้วย Vercel

1. เข้า https://vercel.com สมัครด้วยบัญชี GitHub
2. กด Add New > Project เลือก repository นี้ แล้วกด Deploy (ไม่ต้องตั้งค่าอะไรเพิ่ม)
3. จะได้ลิงก์เว็บ เช่น `https://ชื่อโปรเจกต์.vercel.app`

### 3. ทำ QR code

เปิด `ลิงก์เว็บ/admin.html` ใส่รหัสผ่านของบ่าวสาว แล้วกด "บันทึกรูป QR" นำไปพิมพ์วางในงานได้เลย

## ปรับแต่ง

| อยากเปลี่ยน | แก้ที่ |
| --- | --- |
| ชื่อบ่าวสาว วันที่ ข้อความต้อนรับ สี | `js/config.js` |
| โทนสีรูป (Kodak UltraMax 400 / โทนอุ่นแบบเดิม / ขาวดำ) | `js/config.js` ช่อง `filmStyle` ใส่ `'ultramax'`, `'classic'` หรือ `'bw'` |
| จำนวนรูปต่อคน | Supabase > Table Editor > `app_settings` > `max_shots` (และ `maxShots` ใน `config.js` ให้ตรงกัน) |
| เปิดอัลบั้มรวมทันที หรือเปิดพร้อมกันหลังงาน | Supabase > `app_settings` > `reveal_at` เว้นว่างคือเห็นทันที ใส่วันเวลาคือเปิดตอนนั้น |

## ข้อควรรู้

- จำนวนรูปนับตามเครื่องของแขก ถ้าแขกล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่องจะได้ฟิล์มม้วนใหม่ ซึ่งสำหรับงานแต่งถือว่ารับได้
- ถ้าสัญญาณเน็ตในงานไม่ดี รูปจะรออยู่ในเครื่องและส่งเองเมื่อเน็ตกลับมา
- ถ้าเปิดจากแอป LINE แล้วกล้องไม่ขึ้น เว็บจะมีปุ่มให้ถ่ายด้วยกล้องของเครื่องแทน
- ปุ่มแฟลช (รูปสายฟ้ามุมขวาบนของหน้ากล้อง) กล้องหลังจะเปิดไฟแฟลชของมือถือแป๊บหนึ่งตอนกดถ่าย ใช้ได้กับ Android (Chrome) และ iPhone ที่อัปเดต iOS ใหม่ ๆ ส่วนกล้องหน้าจะใช้จอขาวสว่างเต็มจอช่วยส่องหน้าแทน ถ้าเครื่องหรือเบราว์เซอร์ไม่อนุญาตให้เว็บเปิดไฟ เว็บจะขึ้นบอกและถ่ายต่อได้ตามปกติ
- แพ็กเกจฟรีของ Supabase เก็บได้ 1 GB หรือประมาณ 3,000 รูป และโปรเจกต์ฟรีจะหยุดพักถ้าไม่มีคนใช้ 7 วัน ให้เข้าไปกด Restore ก่อนวันงาน และดาวน์โหลดรูปเก็บไว้หลังงาน

## อัปเดตฐานข้อมูล

- `supabase/update-1.sql` สำหรับโปรเจกต์ที่รัน `setup.sql` ไปก่อนแล้ว: เพิ่มปุ่มลบรูป เปลี่ยนเป็น 25 รูปต่อคน และให้บ่าวสาวเพิ่มฟิล์มรายคนได้ วางใน SQL Editor แล้วกด Run ได้เลย รหัสบ่าวสาวไม่เปลี่ยน รันซ้ำได้
- การรัน `setup.sql` ซ้ำจะตั้งรหัสบ่าวสาวใหม่ตามบรรทัดล่างสุดเสมอ
- เปลี่ยนรหัสบ่าวสาว: `update admin_secret set pass = 'รหัสใหม่' where id = 1;`
- เพิ่มฟิล์มให้แขก: หน้าบ่าวสาว ส่วน "เพิ่มฟิล์มให้แขก" กด +5 แล้วให้แขกกด "เช็กฟิล์มอีกครั้ง" ในหน้ากล้อง
